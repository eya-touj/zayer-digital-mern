# Nessrinou Shoes — prototype front-end

Ouvrir `index.html` dans un navigateur moderne. Une connexion Internet est requise pour Tailwind CDN, Lucide, Google Fonts et les photos distantes.

### Inclus
- Design responsive desktop/tablette/mobile
- Animations au scroll, cartes et boutons animés, éléments flottants
- Filtres, recherche et navigation du carrousel
- Panier interactif (ajout, retrait, quantité, total)
- Favoris, mode sombre, menu mobile, formulaire newsletter de démonstration
- Photo de la boutique fournie par la cliente intégrée à la page

### Avant mise en production
Les produits et prix sont des exemples de présentation. Il faudra les remplacer par le catalogue réel, connecter une API/base de données, les commandes, les stocks, le paiement et les coordonnées officielles de la boutique.
